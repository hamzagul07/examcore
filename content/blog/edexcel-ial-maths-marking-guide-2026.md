Edexcel International A Level Maths scripts are marked for **valid method** and **accurate results**, with **follow-through** where the scheme allows. That is a different dialect from Cambridge’s B/M/A shorthand and from “ChatGPT said this looks fine.” If you only check the final number, you train the wrong skill for WMA/WME/WST units.

## Quick answer

| Idea | What it means in practice |
| :--- | :--- |
| Method | A correct route earns credit even if arithmetic slips later |
| Accuracy | Correct value/form in the place the scheme awards it |
| Follow-through | Later marks can survive an earlier error if the method stays valid |
| Board picker | Use [/mark?board=edexcel](/mark?board=edexcel&subject=WMA11) — not the Cambridge default |
| Grade currency | Marked raw first, then [UMS / cash-in](/blog/edexcel-ial-maths-grade-boundaries-ums-2026) |

## What examiners are looking for

1. **A readable route** — substitution, rearrangement, differentiation step, or model equation written where the mark lives.  
2. **Accepted equivalents** — simplified forms that match the scheme’s allowed answers.  
3. **Exactness when asked** — exact values beat early rounding.  
4. **Units and stated forms** — especially Mechanics (WME) and “give your answer as…”.  
5. **Dependent accuracy** — an early algebra error can wipe later A marks; rebuild from the mistake instead of carrying fantasy numbers.

Self-marking that only ticks green/red on the final line misses most of the paper.

## Practice loop (unit → mark → repair)

1. Sit one **unit** paper under time ([past papers guide](/blog/edexcel-ial-maths-past-papers-guide-2026)).  
2. Self-mark with the official Pearson scheme for that series.  
3. Second-pass the worst question on MarkScheme with the matching unit code (start with [WMA11](/mark?board=edexcel&subject=WMA11)).  
4. Repair the topic that lost the most method marks — not a random playlist.  
5. Only then estimate UMS using [boundaries / cash-in](/blog/edexcel-ial-maths-grade-boundaries-ums-2026).

## Common marking mistakes

| Mistake | Cost | Fix |
| :--- | :--- | :--- |
| Skipping working | No method marks | Write the operation that earns the mark |
| Using Cambridge papers only | Wrong wording/timing | Prefer IAL unit papers |
| Rounding mid-question | Accuracy lost | Keep exact form until asked |
| Ignoring “hence” | Broken dependency | Use the previous result as required |
| Marking with generic AI | Soft on method | Board-native second pass |

## FAQ

### Is Edexcel marking “easier” than Cambridge?

No useful answer. Different schemes, different paper styles. Practise the board you sit.

### Do you award UMS directly?

No. We help you recover **raw** method/accuracy marks. UMS conversion uses Pearson’s tables for that unit/session.

### Which unit should I mark first?

The one you sit next. If you are early Pure, start with WMA11.
