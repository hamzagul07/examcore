Edexcel International A Level **Chemistry** uses the same analytic mark types as other IAL STEM units: **M** for method/working, **A** for accuracy, **B** for independent correct statements, plus follow-through when the method is valid. This guide is for students who sit **WCH** units — not Cambridge 9701 by default.

## How to mark a Chemistry answer

1. Self-mark the Pearson scheme first — note every M/A line you missed.  
2. Photograph or type the worst question into MarkScheme with the matching unit (start with [WCH11](/mark?board=edexcel&subject=WCH11)).  
3. Rebuild one skill (titration calculation, organic mechanism step, equilibrium expression) before the next paper.  
4. Do **not** paste Cambridge mark schemes into an Edexcel sitting and expect the same mark pattern.

## Common traps

| Trap | Fix |
| :--- | :--- |
| Correct idea, missing working | Write the step that earns the M mark |
| Right number, wrong SF/units | Match the question’s required form |
| Early arithmetic error carried forward | Apply FT only when method is valid; otherwise restart |
